# coding-study

자바스크립트를 공부하며 유용한 기능들을 직접 구현해보고, 프로그래머스 코딩테스트 문제를 풀며 기록하는 개인 저장소입니다.
JavaScript 풀이와 함께 Java 풀이도 이 저장소에서 함께 기록하고 있습니다.

---

## 📁 폴더 구조 안내

* **`js-features/`** - 웹사이트에서 쓰이는 유용한 동적 기능 구현
  * `todo-list/` : 할 일 목록 기능
  * `clock/` : 실시간 시계 기능
  * `drag-and-drop/` : 마우스로 요소를 끌어서 놓는 드래그 앤 드롭 기능
  * `password-strength/` : 입력한 비밀번호의 강도를 확인하는 기능
  * `box-move/` : 상자를 이동시키는 기능

* **`programmers/`** - 프로그래머스 코딩테스트 문제 풀이
  * `js/lv0/` : JavaScript로 푼 레벨 0 문제
  * `java/lv0/` : Java로 푼 레벨 0 문제
  * `java/lv1/` : Java로 풀 예정인 레벨 1 문제 (준비 중)
